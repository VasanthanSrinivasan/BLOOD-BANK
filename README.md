# LifeLine Blood Donation Management System

## Run
- Server: copy `.env.example` to `.env`, set MongoDB URI/JWT secret, then `npm install` and `npm run dev`.
- Client: copy `.env.example` to `.env`, then `npm install` and `npm run dev`.

## Sample data
Dashboard, inventory, hospital, request, user and report pages include clearly marked demo records. They are frontend examples and do not persist to MongoDB. Donor Management continues to use the existing backend API.

Never commit `.env`. Rotate any credentials previously shared.
